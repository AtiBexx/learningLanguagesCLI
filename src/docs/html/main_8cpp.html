Sets up the console environment / Konzol környezet beállítása.

EN: This function initializes the Windows console to support UTF-8 character encoding on Windows. And then Enables ANSI mode for screen wiping. HU: Ez a függvény inicializálja a Windows konzolt az UTF-8 karakterkódolás támogatására WINDOWS-on. Továbbá Engedélyezi az ANSI módot a képernyőtőrlés számára.
